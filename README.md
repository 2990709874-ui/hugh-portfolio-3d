# hugh-portfolio-3d

纪辉的 3D 互动个人作品集（静态构建产物）。

- 在线访问：GitHub Pages 部署后地址为 `https://2990709874-ui.github.io/hugh-portfolio-3d/`
- 源码仓库：见 `sen-3d-resume-hugh`（Vite + React Three Fiber）
- 更新方式：在源码仓库执行 `pnpm build` / `npm run build`，将 `web/dist/` 内容覆盖到此仓库，`git push` 即可

## 部署（GitHub Pages）

1. Push 到 `main` 分支
2. Settings → Pages → Source 选 `Deploy from a branch` → `main` / `/ (root)`
3. 等 1~2 分钟生效
